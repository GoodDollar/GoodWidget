## Journey

Frames are composed from instances on the Ecosystem Widget Components page and the Claim / AI Credits component pages, bound to the same tokens. Light and Dark follow the Mode theme. Assumptions: four widgets are pinned to the bottom bar (configurable), the fifth slot is More; the embedded widget's own header is hidden because the wrapper header owns title, network and wallet; the Reown modal is third-party UI and drawn as a placeholder; widget icons are placeholders.

| Step | Frame | Transitions |
| --- | --- | --- |
| 1 | 1 · claim (default) | Tap AI Credits → 4 · Tap More → 6 · Disconnect → 2 |
| 2 | 2 · claim · wallet disconnected | Press Connect Wallet → 3 |
| 3 | 3 · connecting wallet (Reown modal) | Wallet approved → 1 |
| 4 | 4 · switching widget (loading) | Widget loaded → 5 |
| 5 | 5 · AI Credits loaded | Tap Claim → 1 |
| 6 | 6 · More drawer open | Pick a widget → 7 · Close → 1 |
| 7 | 7 · drawer pick · loading | Widget loaded → 1 · Unsupported network → 8 |
| 8 | 8 · widget unavailable on network | Switch network → 1 · or pick another widget |
| 9 | 9 · four widgets · More disabled | Four or fewer widgets: More is disabled |

### Status legend

- **exists**: Reuse as-is. File and export must resolve in the repo (validated).
- **extend**: Reuse an existing component and add behaviour/variants (named in `change`).
- **new**: Does not exist. `proposedFile` is a suggestion, final location is decided in the [Feature].
- **third-party**: Rendered by a third-party SDK. The Penpot frame is a placeholder, nothing to build.
- **slot**: Placeholder for an embedded widget (Claim, AI Credits, ...). Mount the existing widget as-is; nothing to build or restyle.
