## Status legend

- **exists**: Reuse as-is. File and export must resolve in the repo (validated).
- **extend**: Reuse an existing component and add behaviour/variants (named in `change`).
- **new**: Does not exist. `proposedFile` is a suggestion, final location is decided in the [Feature].
- **private**: Exists but is a non-exported const inside a widget file; promote to a shared export if the wrapper must reuse it.
- **third-party**: Rendered by a third-party SDK. The Penpot frame is a placeholder, nothing to build.
- **widget-internal**: Part of an embedded widget's own UI, already built there. The wrapper does not touch it.

## Open questions

- Hiding the embedded widget's own header needs an upstream hideHeader switch in each widget.
